# Retain completed readbacks as coherence snapshots

Color completion previously copied its readback into an observation baseline and also copied guest storage into a raw baseline. Now publication swaps the readback/observation buffer ownership after the GPU request retires. For exact packed BGRA or full Morton storage, observation bytes are also the raw baseline, avoiding the second copy. Pitched/padded and converted raw layouts keep a separate snapshot.

Packed depth publication similarly swaps the readback-word buffer with its raw baseline only when the guest layout and byte size match exactly (tightly packed linear or full GPU Morton). Other layouts retain the original copy. All allocations remain separately owned; no borrowed request pointer outlives retirement. CPU edit detection, component merges, write-watch leases, guest publication and GPU fences are unchanged. Added counters count skipped memcpy payload bytes, not measured physical DRAM traffic.

Native VC3 and Android shared Vulkan builds passed. Existing depth/texture fixtures passed with synchronization validation, including exact bytes, CPU edits, padding, Morton layout, repeated staging reuse, resized/aliased targets and dormant clean-depth owners. These exercise both optimized and fallback layouts.

Sequential local A/B uses /tmp/vc3-no-cpu-extents-vc3 as control and /tmp/vc3-snapshot-ownership-vc3 as candidate, independent copies of /tmp/vc3-no-cpu-extents.cache, identical profiling flags and input, 2,100 frames. No stack sampling, new captures, headset access or APK changes. The unrelated host_input.c edits are present in both binaries and excluded from this commit. Evidence is local, not Quest throughput proof.

Both runs completed 2,100 frames, exit 0. Candidate skipped 35,735,109,632 color and 10,914,250,752 depth snapshot payload bytes (46.65 GB total). These are eliminated memcpy lengths, not measured DRAM bandwidth. Excluding frames with pipeline creation, completion CPU control -> candidate: combat 1.741 -> 1.535 ms, activation 1.908 -> 1.734 ms, held 1.909 -> 1.701 ms (~9–12% lower). Completion wall time was broadly unchanged (4.848 -> 4.753, 4.935 -> 4.936, 4.986 -> 4.974 ms). Draw CPU was similar. Both remained ~60 FPS, candidate p95 20.81–22.32 ms; no pacing improvement is established. This is one sequential local A/B pair with slightly different execution/cache counts, not repeatability or Quest proof. See comparison.json and binary hashes in each report.
