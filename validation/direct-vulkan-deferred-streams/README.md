# Preserve inline vertex streams across deferred submission

The shared xboxrecomp deferred queue copied each inline attribute separately, even when attributes overlapped one interleaved payload. This destroyed the shared layout before Vulkan saw the draw and caused many batches to fall back to expanded attribute snapshots. The queue now sorts and merges overlapping/adjacent inline byte spans, copies each union once and rebases attribute pointers while preserving stride, format and bounds. Guest-backed attributes remain borrowed under the existing executor contract; constants, indices, program snapshots and completion ordering are unchanged. No numeric graphics work moves to the CPU.

The standalone real-queue fixture blocks the consumer, records overlapping/nested/independent attributes, mutates producer storage before replay, then checks contents, shared offsets, guest pointers and constant attributes. It sends8000draws across repeated ring reuse and checks semaphore writes follow all prior draws. It passed; target nv2a_deferred_stream_test is registered under CHIHIRO_VULKAN_CPU_TESTS. Native game and Android xbox_kernel builds passed. An initial attempt to build the Android umbrella target xboxrecomp was corrected to xbox_kernel; fixture registration was moved from disabled graphics-tests to CPU-tests before its CMake build.
