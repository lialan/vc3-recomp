# Packaged device pipeline caches

Implemented shared build-generated compressed cache seeds, validated memory loader, GPU/device/driver UUID selection, startup merge with writable disk cache, and automatic SAVE_DIR persistence. Existing shaders already embed build-time SPIR-V. Quest build script forwards seeds, enforces Qualcomm vendor, and requires seeds for Vulkan releases unless explicitly disabled for training. Direct CMake gate is optional. See runtime/src/gpu/vulkan/PIPELINE_PACKAGING.md.

Validation: native seeded build passed; 120-frame simulator run from fresh save directory exits0/reacheslimit, reports packaged_bytes68774076 / loaded_bytes0, then saves same driver bytes automatically. Simulator seed compressed from68774100 envelope bytes to12923650. This is macOS evidence only; that seed was not included in Android. Focused KosmicKrisp synchronization-validation suite passed existing exact guest-memory/cache coherence plus memory-cache import/merge and11 malformed/incompatible envelope cases. Packager checks valid input, wrong Quest vendor, duplicate identity and truncation. CMake missing-required-seed gate rejected configuration as intended. bash syntax and git diff checks pass.

Android vc3 target cross-built to libmain.so; offline Gradle assembled training APK using staged libraries. ZIP native-library SHA-256 matches the cross-built library. Artifact metadata in android-artifact.json. No install, ADB, device query or headset run. Android build contains no Quest seed: none exists in checked local locations. Existing unrelated host_input.c modification was preserved and is present in workspace-derived binaries, not staged in this change.

This implements packaging and automatic use of device-specific caches, not offline generation of arbitrary Quest pipelines on macOS. Unseen state/program variants or a changed driver can still compile. No full-game no-stutter acceptance claim. A trained Quest3 cache and exact-target cold-disk validation remain necessary for a seeded release. Older performance goal remains paused.
