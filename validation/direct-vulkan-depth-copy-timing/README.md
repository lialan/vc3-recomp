Next implementation opportunity: overlap source-render/depth-copy completion with destination CPU preparation or share compatible depth storage. Do not merely remove the fence wait: source command buffers/descriptors cannot be reused while submitted, both source and destination images must survive, and readback/snapshot wrappers currently assume synchronous copy completion.
