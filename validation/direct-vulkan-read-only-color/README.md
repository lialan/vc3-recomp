# Remove read-only color layout round trips and expose submission phases

Shared render_read previously transitioned color TRANSFER_SRC->TRANSFER_DST->TRANSFER_SRC even without a geometry draw or color clear. Such operations now leave color in TRANSFER_SRC; depth barriers, readback/packing barriers, submit/fence waits and guest publication remain unchanged. Initialization still requires a full clear, which retains color transitions. Resource counters report skipped barriers.

Frame-cost diagnostics now expose existing batch submit/record/retire times and counts plus synchronous render GPU/host times and counts. They aggregate retained and retired surfaces consistently with prior timing counters. No new timestamp queries or waits are introduced; output is conditional on existing profiling settings. Phase totals overlap and must not be added to construct frame time. Synchronous GPU timestamps report zero at displayed precision in the target scenes; that is not proof of zero GPU work.
