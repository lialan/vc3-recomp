# Packaged Vulkan shaders and device pipelines

SPIR-V shaders are compiled by glslc during the build and linked into the shared Vulkan runtime. Pipeline specializations still depend on guest vertex programs, combiner/state variants and the target driver. A desktop cache cannot precompile Quest 3 pipelines.

The shared build embeds one or more trained CHVK cache files, compressed with zlib, into the native library. No sidecar asset path or network download is needed. Runtime selects by Vulkan vendor ID, device ID and pipelineCacheUUID, validates the envelope/checksum, creates the driver cache before creating backend pipelines, and merges a compatible writable cache. Incompatible/driver-rejected data falls back safely. Cache contents are acceleration hints, not a portable executable pipeline archive or a guarantee that the driver never compiles.

Quest 3 uses this path automatically. Its writable cache defaults to `SAVE_DIR/vulkan-pipelines.cache` (the Android app sets SAVE_DIR). `CHIHIRO_VULKAN_PIPELINE_CACHE` overrides the path; an explicitly empty value disables disk persistence but retains packaged seeds. Save occurs at orderly runtime shutdown or the diagnostic frame limit. Force-stopping Android can bypass shutdown; training should use a bounded run or orderly exit. No mid-game cache serialization is added. Runtime loading/saving and build-time packaging share a 512 MiB payload ceiling in `vk_pipeline_cache_file.h`; the earlier 128 MiB ceiling rejected trained caches and prevented new entries from surviving a restart. This limit bounds allocations, not GPU texture residency. A rejected save preserves the previous file and logs the queried size and limit.

## Training and release

1. Build a Vulkan training package with `CHIHIRO_RENDERER=vulkan CHIHIRO_VULKAN_REQUIRE_PIPELINE_CACHE_SEEDS=OFF quest/build.sh vc3`. Other games use the same command with their game ID. This is a build-only script; it does not install or connect to a device.
2. In a separately authorized Quest 3 session, exercise the intended scenes/program/state variants and end cleanly. Preserve the resulting `vulkan-pipelines.cache`, along with the game/source revision, headset OS/driver and coverage notes. The cache is generated by Quest 3's own Vulkan driver. This implementation does not synthesize a Quest cache on macOS or replay unseen pipelines at a loading screen.
3. Supply that file when building the release:

```sh
CHIHIRO_RENDERER=vulkan \
CHIHIRO_VULKAN_PIPELINE_CACHE_SEEDS=/absolute/path/quest3/vulkan-pipelines.cache \
quest/build.sh vc3
```

Quest build.sh requires nonempty seeds for Vulkan releases by default and rejects non-Qualcomm vendor data. Device ID and driver UUID are checked again on the actual device. Direct CMake users can enforce the same gate with `-DCHIHIRO_VULKAN_REQUIRE_PIPELINE_CACHE_SEEDS=ON` and pass `-DCHIHIRO_VULKAN_PIPELINE_CACHE_SEEDS=/absolute/path/cache`. Multiple compatible targets/driver revisions use a semicolon-separated list, one seed per device/UUID. Duplicate identities are rejected; train a single accumulating cache for each identity. The build emits `runtime/src/gpu/vulkan/pipeline-cache-manifest.json` with identities, SHA-256 and compressed sizes. Cache corruption/missing files fail the build.

A matching Quest 3 seed is necessary for a Quest 3 release; do not supply simulator seeds. Driver updates can invalidate it. Unseen states still compile and enter the writable cache. Validate first launch with an empty writable cache on the exact target scenes before claiming no compilation stutters. `packaged_bytes` reports accepted embedded data; `loaded_bytes` reports accepted disk data. These counters do not prove all gameplay pipelines are covered.

Quest build.sh discovers per-game seeds placed under `games/<id>/pipeline-cache/quest3/*.cache` unless CHIHIRO_VULKAN_PIPELINE_CACHE_SEEDS is explicitly set. Seeds are compiled from the game's shaders, so none is committed: each user trains their own, and with none supplied the seed requirement defaults to OFF. Seed coverage and device provenance must accompany each game artifact. The initial implementation was validated locally; subsequent real-device training evidence is under validation/direct-vulkan-quest-driver-cache.

For a cold training run only, `CHIHIRO_GPU_FENCE_TIMEOUT_MS=600000` extends the strict semaphore watchdog from30seconds to at most10minutes. It never acknowledges an unfinished fence. Values outside30000..600000ms retain the default. Keep this override unset during packaged-cache acceptance. The Quest runner supports `--env NAME=VALUE`, exports the writable cache before cleanup, and must run under the shared quest3-lock for the entire device session.
